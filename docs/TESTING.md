脚本版本为 1.5.1，播放器功能沿用 1.5.0。本次发布补充仓库元数据、中文文档、固定依赖与自动回归检查；测试中的皮肤替换为自建最小夹具，发布仓库不再依赖本地下载的第三方播放器源码或完整样式。


本次在本地 Node.js 25.8.2 / npm 11.11.1 环境检查通过：用户脚本语法检查及 81 项行为检查均通过。另将仅含待公开文件的 ZIP 解压到干净目录，重新执行 `npm ci` 与 `npm test`，同样通过 81 项检查，确认测试不依赖被排除的本地研究文件。GitHub 自动检查使用 Node.js 22，具体运行结果以仓库 Actions 页面为准。

主要覆盖长按启动与释放、倍速恢复、上下键的音量/倍速分工、静音、字幕切换、独立字幕显示、外观和透明度保存、恢复默认、旧设置兼容、全屏容器归属、控制栏接入、章节切换与卸载清理。

## 哪些结论不能从测试中推出

媒体播放、TextTrack 和全屏接口均有模拟，jsdom 不负责实际渲染视频和完整页面布局。因此这些检查不能证明真实课程页的视觉效果、真实键盘的全部行为、播放器后续改版后的适配、移动端或其他浏览器兼容性。

公开整理初始阶段尝试连接 Chrome 课程页未成功，没有将历史截图当作新版的真实页面验收。

## 同日后续：真实课程页界面核验

用户在 Chrome 中重新登录后，已在真实启航课程页面确认：底部“字幕设置”位于倍速按钮左侧，设置面板可以展开和收起，面板内显示字号、位置、颜色、透明度、字重、字体及描边选项。操作结束时收起面板，视频保持原有的暂停状态。

README 已加入本轮浏览器直接截取的控件区域截图，画面范围避开了账号水印、地址栏和章节学习记录。截图中的字号 26、透明度 15% 是当时页面配置，不代表默认值。

后续补充了使用者提供并要求公开展示的完整课程页面截图，用红框标出“倍速播放中 3×”提示。它是补充的界面展示材料，不计作新一轮自动测试或全部快捷键验收。

本轮真实页面核验仅覆盖上述界面接入与面板展开/收起，不等于重新完成所有快捷键、全屏切换、字幕同步或跨浏览器测试。

## 本地预览

运行 `npm run preview` 后打开 `http://127.0.0.1:18765/ark/record/preview`。页面使用自制 Canvas 画面、字幕和控制栏，便于人工检查按钮位置、弹出面板、透明度与全屏。此页面的检查同样不能代替真实启航课程验证。

## 提交修复时建议人工核对

在有权观看的课程中核对长按/松开、暂停时长按、全屏切换、字幕设置与关闭、字体回退、透明度两端值、课程切换以及输入框内的按键避让。复现材料只保留必要信息，个人账号资料和完整课程链接不应进入公开 Issue。
